# 3. Guest System Verification

The following four commands were run on `sna-srv01` to verify the installed system.

## 3.1 `hostnamectl`

- Static hostname: `sna-srv01`
- Operating System: Ubuntu 26.04.1 LTS
- Kernel: Linux 7.0.0-30-generic
- Architecture: arm64
- Virtualization: VMware

Confirms the VM hostname, installed OS, architecture, kernel, and virtualization platform.

## 3.2 `whoami`

`davin`

Confirms the currently logged-in account.

## 3.3 `ip -br address`

- `lo` → `127.0.0.1/8`
- `enp2s0` → UP, IPv4 `192.168.202.130/24`

`lo` is the local loopback interface. `enp2s0` is the VM's network interface, which received its IPv4 address via DHCP.

## 3.4 `lsblk`

- `nvme0n1` → 20 GB virtual disk
- `nvme0n1p1` → 953 MB → `/boot/efi`
- `nvme0n1p2` → 1.8 GB → `/boot`
- `nvme0n1p3` → 17.3 GB
- `ubuntu--vg-ubuntu--lv` → 10 GB → mounted at `/`

Shows the 20 GB virtual disk divided into EFI and boot partitions, with Ubuntu's LVM logical volume mounted as the root filesystem `/`.

# 6. Reflection

## 6.1 Which computer is the host, and which operating system is the guest?

My MacBook M4 Max running macOS is the host computer. Ubuntu 26.04.1 LTS ARM64 running inside VMware Fusion is the guest operating system.

## 6.2 How does the ISO differ from the virtual hard disk?

The ISO is installation media used to install Ubuntu. The virtual hard disk stores the installed operating system, configuration, and files. After installation, the ISO can be disconnected and the VM boots from the virtual disk.

## 6.3 Why do we use NAT and DHCP for this first installation?

NAT allows the VM to access the network through the host Mac without exposing the VM directly to the external network. DHCP automatically assigns the VM an IP address, so manual static network configuration is not required for this first lab.

## 6.4 Why record a baseline before making the next configuration change?

A baseline gives us a known working state. If a later configuration causes a problem, we can return to the snapshot instead of reinstalling and configuring the server again.
